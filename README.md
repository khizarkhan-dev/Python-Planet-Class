# Python Planet Class

This is a Python Object-Oriented Programming (OOP) lab focused on building a custom `Planet` class. 

## Features
- **Attribute Validation:** Uses `isinstance()` to ensure the name, planet type, and star are strings.
- **Empty String Check:** Raises a `ValueError` if any of the attributes are left empty.
- **Custom Methods:** Includes an `orbit()` method to describe the planet's movement.
- **Dunder Methods:** Implements `__str__` to provide a clean, readable string representation of the planet object.

## How to Run
1. Clone the repository.
2. Run `python planet_class.py` in your terminal to see the output of the instantiated planet objects.
